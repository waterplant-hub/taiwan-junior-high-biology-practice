# 生物考古題

臺灣國中教育會考與國中基測的生物歷屆試題練習網站。學生可依章節或考試年度練習，作答後查看得分、錯題、官方答案，以及清楚標示為 AI 生成的詳解與各選項分析。

## 目前範圍

- 103–115 年國中教育會考生物題，共 184 題（已排除偏理化題）
- 90–102 年國中基測生物題，共 383 題；已排除偏理化題與現行不考的早期地球環境題
- 目前合計 567 題，均有官方答案與必要題圖；會考另有官方答對率、鑑別度，基測未公布的統計不臆測
- 題組保留共同閱讀圖幹，抽題與錯題重練時不拆散子題
- 章節練習、年度練習、錯題重練
- 本機作答歷史、章節表現、匯出／匯入／清除
- 無帳號、無教師後台、無學生資料回傳

## 資料原則

- 題目與正確答案以國中教育會考官方公開資料為準。
- 每題保留年度、自然科原題號、官方題本與答案來源。
- 詳解與各選項錯因保留 `AI 生成` 標示；人工審閱後只增加審閱狀態，不改稱官方解析。
- 章節名稱採主流教科書共通、學生熟悉的用語，不在學生介面顯示課綱代碼。
- 年度模式保留原題與選項順序；章節／錯題模式只打亂標記為安全的選項。
- 每題另有機器可讀的章節、單元、別名、概念、評量能力、題型與改題規則，供日後以 AI 按單元參考出題；這些中繼資料不顯示在學生介面。

## 本機開發

需求：Node.js 22.13 以上與 pnpm。

```bash
pnpm install
pnpm run dev
pnpm run build
pnpm test
```

## 題庫與容量

正式題庫只保留正規化文字資料與網站用最佳化圖片。官方原始 PDF、OCR 中間檔、頁面渲染圖與精修暫存資料已在內容確認後移除，使 GitHub 儲存庫維持小型並適合網站發布。

## 非官方聲明

本專案是獨立製作的非官方學習工具，並非教育部、國中教育會考全國試務會或臺師大心測中心官方服務。若轉錄內容與官方原檔不一致，應以官方公告與題本為準。
