# 生物考古題

臺灣國中教育會考與國中基測的生物歷屆試題練習網站。學生可依章節或考試年度練習，作答後查看得分、錯題、官方答案，以及清楚標示為 AI 生成的詳解與各選項分析。

目前版本：**v1.0**；目前收錄 **567 題**。

## 線上使用

- 線上網站：[https://taiwan-junior-high-biology-practice.waterplant.chatgpt.site/](https://taiwan-junior-high-biology-practice.waterplant.chatgpt.site/)
- GitHub 儲存庫：[https://github.com/waterplant-hub/taiwan-junior-high-biology-practice](https://github.com/waterplant-hub/taiwan-junior-high-biology-practice)

網站可在手機、平板與電腦使用，不需登入。

## 目前範圍

- 103–115 年國中教育會考生物題，共 184 題（已排除偏理化題）。
- 90–102 年國中基測生物題，共 383 題；已排除偏理化題與現行不考的早期地球環境題。
- 合計 567 題，均有官方答案與必要題圖；會考另有官方答對率、鑑別度，基測未公布的統計不臆測。
- 題組保留共同閱讀圖幹，抽題與錯題重練時不拆散子題。
- 提供章節練習、年度練習、錯題重練、章節表現與紀錄匯出／匯入。

## 資料原則

- 題目與正確答案以國中教育會考官方公開資料為準。
- 每題保留年度、自然科原題號、官方題本與答案來源。
- 詳解與各選項錯因保留 `AI 生成` 標示；人工審閱後只增加審閱狀態，不改稱官方解析。
- 章節名稱採主流教科書共通、學生熟悉的用語，不在學生介面顯示課綱代碼。
- 年度模式保留原題與選項順序；章節／錯題模式只打亂標記為安全的選項。
- 每題另有機器可讀的章節、單元、別名、概念、評量能力、題型與改題規則，供日後按單元整理與出題；這些中繼資料不顯示在學生介面。

## 學生資料與使用分析

- 作答歷史與錯題紀錄只儲存在目前瀏覽器的本機儲存空間，不會自動同步到其他裝置。
- 網站不要求帳號，不蒐集姓名、班級，也不把作答選項或成績傳給教師。
- Google Analytics 4 只記錄整體瀏覽、開始練習與完成練習等事件，不傳送姓名、作答選項或成績。
- 學生主動複製摘要或匯出紀錄時，完整紀錄才會離開目前畫面。

## 本機開發

需求：Node.js 22.13 以上與 pnpm。

```bash
pnpm install
pnpm run dev
pnpm run lint
pnpm run build
pnpm test
```

主要結構：

- `app/`：頁面、題庫介面、資料處理與本機紀錄。
- `public/`：題圖與網站靜態資源。
- `tests/`：建置後的內容與頁面檢查。
- `.openai/hosting.json`：現有 Sites 專案識別資訊；維護時應沿用，不要另建同名網站。

## 維護與發布

本專案的原始碼以 `main` 分支為準，正式網站由 Sites 發布，不使用 GitHub Pages。

每次更新題庫或網站時：

1. 核對新增題目的年度、原題號、官方答案、來源與必要題圖。
2. 確認題組未被拆散、選項重排規則安全，並同步更新畫面與 README 的題數。
3. 執行 `pnpm run lint`、`pnpm run build` 與 `pnpm test`。
4. 實際抽查章節練習、年度練習、錯題紀錄與匯出／匯入。
5. 提交相同的已驗證原始碼，再更新既有 Sites 專案並檢查正式網址。

正式題庫只保留正規化文字資料與網站用最佳化圖片。官方原始 PDF、OCR 中間檔、頁面渲染圖與精修暫存資料不納入正式儲存庫。
